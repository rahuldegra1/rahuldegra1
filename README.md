## 👨‍💻 About Me

- 🚀 **Backend & Distributed Systems:** Engineering robust backend architectures, distributed DAG schedulers, and REST/gRPC microservices with **FastAPI**, **SQLAlchemy**, **PostgreSQL**, and **Redis**.
- 🧠 **Applied ML & Computer Vision:** Fine-tuning and benchmarking computer vision models (**ResNet**, **YOLOv11**), building multimodal search with **CLIP + ChromaDB**, and optimizing model latency via **ONNX Runtime** and **MLflow**.
- 🖥️ **Local AI & Automation:** Implementing low-latency local inference routing architectures using open-weight models (**Qwen2.5**, **LLaVA**) and desktop automation runtimes.
- ⚙️ **Engineering Standards:** Modular domain-driven design, strict schema validation (`Pydantic`), **Docker** containerization, and automated **GitHub Actions CI/CD** testing.
