## About

I build systems where correctness and performance are non-negotiable.

- 🏗️ **Distributed Systems & Backend** — Async FastAPI services, gRPC streaming, PostgreSQL with `SKIP LOCKED` concurrency, Redis task queues
- 🤖 **Applied ML & Inference** — PyTorch fine-tuning, ONNX Runtime optimization, CLIP multimodal search, YOLOv11 detection pipelines
- 🖥️ **Local AI & Automation** — Low-latency local inference routing with open-weight models (Qwen2.5, LLaVA) and desktop automation
- 🔒 **Engineering Rigour** — Pydantic v2 contracts, constant-time auth (`secrets.compare_digest`), Prometheus telemetry, Docker + GitHub Actions CI/CD
